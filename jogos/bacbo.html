❓ COMO JOGAR — PONTO MAIOR

Objetivo

Dois dados para o Jogador 1 (azul) e dois para o Jogador 2 (vermelho). Quem tiver a pontuação mais alta vence.

Pontuação

  • A pontuação é a soma dos dois dados (ex.: 4+6=10; 5+6=11). Quem tiver o ponto maior vence.

Apostas

  • Jogador 1 (azul): paga 1 para 1 se o Jogador 1 vencer.
  • Jogador 2 (vermelho): paga 1 para 1 se o Jogador 2 vencer.
  • Empate: não há aposta de empate. Se as pontuações forem iguais, a aposta é devolvida.
  • Aposta mínima 2 e máxima 200 créditos por aposta. Total máximo por rodada: 200.
